🔍 Revit Visibility Diagnostic (R24)

คู่มือย่อยนี้สร้างจากข้อมูลใน Custom Tools.html เพื่อให้เนื้อหาการติดตั้งตรงกับคู่มือหลัก

ภาพรวม

เคยสงสัยไหมครับว่า *"ทำไมฉันถึงมองไม่เห็นโมเดลชิ้นนี้ใน View?"*

ปลั๊กอิน Visibility Diagnostic คือผู้ช่วยที่จะมาประหยัดเวลาของคุณ! ด้วยหน้าต่างวิเคราะห์แบบ Modeless ที่เป็นมิตรต่อผู้ใช้งาน คุณสามารถตรวจสอบสาเหตุทั้งหมดที่ทำให้โมเดลหายไปใน View นั้นๆ ได้แบบ Real-time

บอกลาการคลิกสุ่มหาใน Visibility/Graphics (VV), View Ranges หรือ Filters แบบเดิมๆ ไปได้เลย!

การใช้งาน

🔌 การใช้งานฝั่ง C# Addin

  • เปิดโปรแกรม Revit ที่ติดตั้ง Add-in ไว้แล้ว
  • มองหาแท็บเมนู MTC Tools หรือ BIMTools บนแถบ Ribbon
  • คลิกปุ่มคำสั่งของเครื่องมือนี้ (IExternalCommand) หน้าต่าง UI จะแสดงขึ้นมา
  • ทำตามขั้นตอนที่ระบุบนหน้าต่าง UI เพื่อจัดการกับโมเดล และกด Execute

การติดตั้ง

🔌 การติดตั้งฝั่ง C# Addin

  • ไปที่โฟลเดอร์ Release และเลือกชุดที่ตรงกับ Revit ที่ใช้งาน (เช่น Release\Revit2024, Release\Revit2025, Release\Revit2026)
  • คัดลอกไฟล์ .addin ชั้นนอก พร้อมโฟลเดอร์ชื่อเครื่องมือที่อยู่ข้างกันทั้งโฟลเดอร์ ห้ามหยิบเฉพาะ DLL จาก bin, obj หรือจากในโฟลเดอร์ย่อย
  • นำไฟล์ .addin และโฟลเดอร์ชื่อเครื่องมือไปวางคู่กันที่โฟลเดอร์ Addins ของ Revit:

%APPDATA%\Autodesk\Revit\Addins\20XX\

  • ตรวจสอบในไฟล์ .addin ว่าพาธในแท็ก <Assembly> ชี้ไปที่ ชื่อโฟลเดอร์\ชื่อไฟล์.dll เช่นเดียวกับโครงสร้าง Release package
  • เปิดโปรแกรม Revit ระบบจะถามหาสิทธิ์การโหลด ให้กดปุ่ม Always Load

💡 ภาพรวม (Overview)

เคยสงสัยไหมครับว่า *"ทำไมฉันถึงมองไม่เห็นโมเดลชิ้นนี้ใน View?"*

ปลั๊กอิน Visibility Diagnostic คือผู้ช่วยที่จะมาประหยัดเวลาของคุณ! ด้วยหน้าต่างวิเคราะห์แบบ Modeless ที่เป็นมิตรต่อผู้ใช้งาน คุณสามารถตรวจสอบสาเหตุทั้งหมดที่ทำให้โมเดลหายไปใน View นั้นๆ ได้แบบ Real-time

บอกลาการคลิกสุ่มหาใน Visibility/Graphics (VV), View Ranges หรือ Filters แบบเดิมๆ ไปได้เลย!

✨ ฟีเจอร์หลัก (Key Features)

  • 🚀 วิเคราะห์แบบ Real-time: ใช้งานผ่านหน้าต่าง WPF แบบ Modeless สามารถเปิดค้างไว้ระหว่างทำงานและคลิกเช็คโมเดลต่างๆ ได้ตลอดเวลา
  • 🎯 ค้นหา View ที่ต้องการได้ทันที: มีช่อง ComboBox ที่รองรับระบบพิมพ์ค้นหา (Filter-as-you-type) ช่วยให้เข้าถึง View ที่ต้องการได้อย่างรวดเร็ว
  • 🚦 แสดงผลลัพธ์ด้วยสีสันชัดเจน: อ่านค่าสถานะได้ทันที (🟢 สีเขียว = แสดงผลปกติ, 🔴 สีแดง = ถูกซ่อน/ถูกบล็อก)
  • 🧩 ตรวจสอบครอบคลุมทุกจุด: เช็คเงื่อนไขเหล่านี้ให้อัตโนมัติ:
  • โมเดลถูกสั่งซ่อนถาวรอยู่หรือไม่? (Hide in View)
  • หมวดหมู่ (Category) หรือ Subcategory ถูกซ่อนไว้หรือไม่?
  • โมเดลหลุดกรอบ Crop Region ไปหรือเปล่า?
  • Workset ถูกปิด หรือถูกซ่อนใน View นี้หรือไม่?
  • โดน View Filters ทับซ้อนจนมองไม่เห็นหรือไม่?
  • การตั้งค่า Phase ส่งผลต่อการมองเห็นไหม?
  • หลุดระยะ View Range ไปหรือไม่? (สำหรับมุมมองแปลน)

🚀 วิธีใช้งาน (How to Use)

  • เปิด Autodesk Revit 2024 และเปิดโปรเจกต์ของคุณ
  • ไปที่แท็บ Ribbon: BIMTools
  • ในพาเนล Diagnostics ให้คลิกที่ปุ่ม Visibility Diagnostic R24
  • หน้าต่างเครื่องมือจะปรากฏขึ้น ให้กรอกรหัส Element ID ของโมเดลที่หายไป
  • พิมพ์ค้นหาและเลือก Target View ที่คุณกำลังเจอปัญหา
  • คลิกปุ่ม Check Visibility เพื่อดูสาเหตุที่แท้จริงว่าทำไมโมเดลถึงถูกซ่อนไว้!
